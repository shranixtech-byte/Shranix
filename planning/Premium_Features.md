## Monetization Strategy

Premium features are designed to provide clear upgrade value for growing businesses. The strategy is to offer a **generous free/starter tier** that solves core problems, then unlock advanced capabilities through paid tiers.

## Feature Unlocking Mechanism

- **License Key** — Encrypted key file containing feature flags
- **Online Validation** — Periodic license check (configurable interval)
- **Offline Fallback** — Offline machines use cached license (renewal required periodically)
