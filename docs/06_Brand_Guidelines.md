## Brand Identity

### Brand Name

**SHRANIX Krushi ERP**

- **SHRANIX** — Derived from "Shrani" (श्रृंखला = chain/series in Sanskrit) + "X" representing technology and transformation.
- **Krushi** (कृषी) — Sanskrit for agriculture.
- **ERP** — Enterprise Resource Planning.

### Tagline

> _"Empowering Agribusiness"_

### Brand Voice

| Attribute        | Description                         |
| ---------------- | ----------------------------------- |
| **Professional** | Authoritative but approachable      |
| **Clear**        | No jargon, no fluff                 |
| **Confident**    | Knows the domain, respects the user |
| **Supportive**   | Helpful, never condescending        |

### Tone by Channel

| Channel        | Tone                                                                             |
| -------------- | -------------------------------------------------------------------------------- |
| In-app copy    | Direct, minimal, instructional                                                   |
| Documentation  | Technical but readable                                                           |
| Marketing      | Aspirational, benefit-focused                                                    |
| Error messages | Human, solution-oriented ("Something went wrong. We've logged this. Try again.") |

## Logo Usage

_Logo assets to be designed and stored in `assets/brand/`_

### Logo Variations

- **Primary** — Full logo with icon + wordmark (horizontal)
- **Icon Only** — Standalone icon (favicon, app icon)
- **Monochrome** — Single-color variant for dark backgrounds

### Clear Space

Maintain a minimum clear space equal to the height of the "S" in SHRANIX on all sides.

### Don'ts

- ❌ Do not stretch or distort the logo
- ❌ Do not change the logo colors
- ❌ Do not place on low-contrast backgrounds
- ❌ Do not add shadows or effects
