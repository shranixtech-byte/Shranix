```
TypeError: this.requestContext.getContext is not a function
  at AuditService.log src/common/services/audit.service.ts:257:64
```

**H17 added line 257:**

```typescript
const _requestId = params.requestId ?? this.requestContext.getContext().requestId ?? null;
```
